# Правила работы с Markdown

Редактор Jira Cloud поддерживает сокращения Markdown: разметка
превращается в форматирование прямо при вводе. Раздел описывает, какие
элементы разметки использовать в задачах и как писать страницы этого
руководства.

## Разметка в задачах Jira

| Элемент | Как ввести | Когда использовать |
| --- | --- | --- |
| Заголовок | `## Контекст` | Разделы описания по шаблону |
| Полужирный | `**текст**` | Ключевое условие или предупреждение, не чаще раза на раздел |
| Курсив | `*текст*` | Не используется |
| Нумерованный список | `1.` и пробел | Шаги, последовательность действий |
| Маркированный список | `-` и пробел | Равноправные элементы |
| Флажок | `[]` и пробел | Критерии приёмки, чек-листы |
| Код в строке | `` `текст` `` | Имена файлов, параметров, значений, команд |
| Блок кода | ` ``` ` | Команды, запросы, логи, конфигурация |
| Цитата | `>` и пробел | Дословное сообщение пользователя или текст ошибки |
| Ссылка | `[текст](адрес)` | Ссылки на макеты, документацию, страницы |

### Заголовки

- В описании используются заголовки второго и третьего уровня. Первый
  уровень не используется: его роль выполняет тема задачи.
- Названия заголовков берутся из шаблона и не меняются.

### Блоки кода

- Для блока кода указывается язык: `json`, `sql`, `bash`, `text`.
- Перед блоком одной фразой объясняется, что это: запрос, ответ, лог.
- Пароли, токены и персональные данные в блоке кода заменяются на
  `***` или тестовые значения.

Пример фрагмента описания ошибки:

````markdown
## Фактический результат

Сервер возвращает ответ:

```json
{ "status": 500, "error": "NullPointerException" }
```
````

### Ссылки

- Текст ссылки описывает целевой материал: «макет корзины в Figma», а не
  «здесь» или «ссылка».
- Ссылки на другие задачи Jira не оформляются вручную: достаточно указать
  ключ задачи, например `SHOP-123`, — Jira сама преобразует его в ссылку.

### Wiki-разметка

В старых версиях Jira Server и в некоторых интеграциях используется
wiki-разметка Jira. Соответствие основных элементов:

| Markdown | Wiki-разметка Jira |
| --- | --- |
| `## Заголовок` | `h2. Заголовок` |
| `**полужирный**` | `*полужирный*` |
| `` `код` `` | `{{код}}` |
| ` ```json ` | `{code:json}` |
| `> цитата` | `{quote}цитата{quote}` |
| `[текст](адрес)` | <code>[текст&#124;адрес]</code> |

## Разметка страниц руководства

Страницы руководства хранятся в каталоге `docs` и проверяются линтером
markdownlint.

- Имя файла пишется латиницей в нижнем регистре, слова разделяются
  дефисом: `templates.md`, `error-messages.md`.
- На странице один заголовок первого уровня; уровни заголовков не
  пропускаются.
- Перед заголовком, списком, таблицей и блоком кода — пустая строка.
- Маркированные списки оформляются дефисом `-`.
- Таблицы оформляются с выравниванием `| --- |` и заголовками столбцов.
- Каждая новая страница добавляется в раздел `nav` файла `mkdocs.yml`.
- Перед отправкой изменений выполняется `mkdocs build --strict`.
