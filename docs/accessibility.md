# Доступность текста

Задачу в Jira читают не только с монитора: её открывают с телефона,
слушают через экранный диктор, переводят автоматическим переводчиком.
Раздел описывает, как писать задачи, понятные всем участникам команды,
включая людей с нарушениями зрения, дальтонизмом и дислексией.

## Простой язык

- Пишите короткими предложениями — не более 20 слов.
- Один абзац — одна мысль, не более 4–5 предложений.
- Объясняйте термины, которых нет в [глоссарии](glossary.md), при первом
  упоминании.
- Не используйте сленг, иронию и метафоры: их неправильно понимают
  переводчики и люди, для которых русский язык не родной.

## Структура

- Делите описание на разделы с заголовками по [шаблону](templates.md):
  экранный диктор позволяет переходить между заголовками.
- Не пропускайте уровни заголовков: после `##` идёт `###`, а не `####`.
- Не используйте полужирный текст вместо заголовков: диктор не
  распознаёт его как раздел.
- Оформляйте перечисления списками, а не строками через запятую.

## Цвет и выделение

- Не передавайте смысл только цветом. Статус пишется словом: «Ошибка»,
  «Успешно», а не красным или зелёным текстом.
- Не выделяйте текст цветом в редакторе Jira: при тёмной теме он может
  стать нечитаемым.
- Не пишите целые слова и фразы прописными буквами: диктор читает их по
  буквам, а текст хуже воспринимается.

| Неправильно | Правильно |
| --- | --- |
| Красным выделены поля, которые надо исправить | Исправить поля «Телефон» и «Индекс» |
| ВАЖНО: НЕ ЗАКРЫВАТЬ ЗАДАЧУ | **Внимание:** задачу не закрывать до выпуска 2.15 |

## Изображения и вложения

- Снимок экрана дополняет текст, но не заменяет его. Текст ошибки и
  значения полей дублируются в описании.
- У изображения в описании заполняется альтернативный текст (alt-текст):
  что изображено и что на нём важно.
- Видео и записи экрана сопровождаются шагами воспроизведения в тексте.
- Схемы и диаграммы сопровождаются кратким текстовым пересказом.

| Неправильно | Правильно |
| --- | --- |
| `![](image001.png)` | `![Форма оплаты: под полем «Номер карты» ошибка «Неверный формат»](card-error.png)` |

## Ссылки

- Текст ссылки описывает цель: «макет формы оплаты», а не «тут» или
  «по ссылке». Диктор может зачитывать список ссылок без окружающего
  текста.
- Не вставляйте длинные адреса как текст ссылки.
- Если ссылка ведёт на файл, указывайте формат и размер: «отчёт о
  нагрузке (PDF, 2 МБ)».

## Таблицы

- Используйте таблицы только для данных, которые сравниваются по
  одинаковым признакам, а не для вёрстки.
- У каждой таблицы есть строка заголовков с однозначными названиями
  столбцов.
- Не объединяйте ячейки и не оставляйте их пустыми: ставьте «—».

## Эмодзи и спецсимволы

- Не заменяйте слова эмодзи: диктор зачитывает их названия, например
  «красный круг».
- Не используйте символы псевдографики (стрелки из `->`, рамки из `=`)
  для передачи смысла.

## Чек-лист доступности

- [ ] Смысл не передаётся только цветом или расположением.
- [ ] Описание разделено заголовками, уровни не пропущены.
- [ ] Текст ошибки продублирован текстом, а не только снимком экрана.
- [ ] У изображений заполнен альтернативный текст.
- [ ] Тексты ссылок описывают цель.
- [ ] Нет фраз, написанных прописными буквами.
