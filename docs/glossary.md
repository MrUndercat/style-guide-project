# Словари и глоссарии

Раздел фиксирует единые названия понятий, которые используются в задачах
Jira. Одно понятие во всех задачах называется одинаково.

## Глоссарий

Бэклог (Backlog)
:   Упорядоченный список задач, которые ещё не взяты в спринт.

Критерии приёмки (Acceptance criteria)
:   Проверяемые условия, при выполнении которых задача считается
    выполненной.

Обходной путь (Workaround)
:   Способ получить нужный результат, несмотря на ошибку.

Окружение, стенд (Environment)
:   Экземпляр системы, на котором выполняется проверка: test, stage, prod.

Определение готовности (Definition of Done, DoD)
:   Общие для команды условия, которые выполняются для любой задачи
    перед закрытием.

Оценка (Estimate)
:   Ожидаемая трудоёмкость задачи в стори-поинтах или часах.

Спринт (Sprint)
:   Фиксированный период работы команды, обычно две недели.

Стори-поинт (Story point)
:   Условная единица относительной сложности задачи.

Шаги воспроизведения (Steps to reproduce)
:   Последовательность действий, которая приводит к ошибке.

## Сокращения

| Сокращение | Расшифровка |
| --- | --- |
| AC | Критерии приёмки (Acceptance criteria) |
| API | Программный интерфейс приложения |
| DoD | Определение готовности (Definition of Done) |
| PR | Pull Request, запрос на слияние изменений |
| QA | Тестирование, отдел контроля качества |
| UI | Пользовательский интерфейс |

## Словарь «правильно — неправильно»

| Используйте | Не используйте |
| --- | --- |
| ошибка (в теме и типе задачи — Bug) | баг, бага, косяк |
| задача | таска, тикет |
| исполнитель | ассигни |
| снимок экрана | скрин, скриншот |
| стенд | контур, среда (в одной задаче вперемешку) |
| выпуск, релиз | релиз, выкатка, деплой (в значении «выпуск для пользователей») |
| критерии приёмки | АК, акцептанс |
| развернуть | задеплоить, выкатить |

## Утверждённые метки

| Метка | Назначение |
| --- | --- |
| `tech-debt` | Технический долг |
| `security` | Безопасность |
| `ux` | Улучшение пользовательского опыта |
| `performance` | Производительность |
| `regression` | Ошибка в ранее работавшей функции |
| `documentation` | Изменения документации |
