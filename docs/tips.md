# Точечные рекомендации

Раздел собирает короткие советы для частых ситуаций и чек-лист, по
которому задача проверяется перед взятием в работу.

## Частые ситуации

### Ошибка воспроизводится не всегда

Укажите частоту воспроизведения в формате «N из M попыток» и условия, при
которых ошибка проявлялась: время, объём данных, действия перед ошибкой.

### Задача слишком большая

Если задачу нельзя выполнить за один спринт, разделите её на несколько
Story или Task и объедините эпиком. Подзадачи не используются для
дробления больших задач между разными командами.

### Требования изменились во время работы

Обновите описание и критерии приёмки, а в комментарии кратко укажите, что
изменилось и почему. Не оставляйте новые требования только в
комментариях.

### Нашли дубликат

Закройте более позднюю задачу с решением «Дубликат», укажите связь
«дублирует» и перенесите в основную задачу полезную информацию.

### Задача заблокирована

Укажите связь «заблокирована» с блокирующей задачей. Если блокирует
внешняя команда, опишите в комментарии, к кому обращались и когда.

### Ошибка в продуктивной среде

Ставьте приоритет Highest или High, укажите количество затронутых
пользователей и время начала проблемы. Персональные данные клиентов в
задачу не копируются.

## Чего избегать

- Тема из одного слова: «Логин», «Отчёт», «Баг».
- Описание в виде одной ссылки на чат или письмо.
- Несколько несвязанных проблем в одной задаче.
- Снимок экрана вместо текста ошибки: текст нельзя найти поиском.
- Назначение задачи на себя «на всякий случай» без намерения выполнить.

## Чек-лист готовности задачи {#checklist}

Перед переводом задачи в статус «Готова к работе» проверьте:

- [ ] Тип задачи соответствует содержанию.
- [ ] Тема не длиннее 80 символов и построена по правилу для типа задачи.
- [ ] Описание заполнено по шаблону, пустые разделы удалены.
- [ ] Критерии приёмки проверяемы и не содержат оценочных слов.
- [ ] Указаны приоритет, компонент и эпик.
- [ ] Термины соответствуют глоссарию.
- [ ] Во вложениях и блоках кода нет паролей, токенов и персональных данных.
- [ ] Связанные задачи указаны через поле связей.
