# Стиль изложения

Раздел описывает, каким языком пишутся задачи: тон, построение фраз и
обращение к читателю.

## Тон

Пишите нейтрально и по-деловому. Задача — рабочий документ, а не письмо
коллеге: в ней нет эмоций, оценок и разговорных оборотов.

| Неправильно | Правильно |
| --- | --- |
| Опять всё сломалось на логине!!! | Форма входа возвращает ошибку 500 при вводе корректного пароля |
| Надо бы как-нибудь ускорить отчёт | Сократить время формирования отчёта «Продажи» до 5 секунд |

## Тема задачи {#summary}

Тема (Summary) — главная строка задачи, которую видят в доске, поиске и
уведомлениях.

- Длина темы — не более 80 символов.
- Тема истории и задачи начинается с глагола в инфинитиве совершенного
  вида: «Добавить», «Исправить», «Перенести».
- Тема ошибки описывает симптом по схеме «Где — что происходит — при каком
  условии».
- Тема не содержит номеров задач, имён исполнителей и дат: для этого есть
  отдельные поля.

| Тип | Неправильно | Правильно |
| --- | --- | --- |
| Story | Фильтр | Добавить фильтр заказов по статусу |
| Task | Обновление библиотеки | Обновить Spring Boot до версии 3.3 |
| Bug | Не работает корзина | Корзина: товар не удаляется при нажатии «Удалить» |

## Предложения

- Одно предложение — одна мысль. Длина предложения — не более 20 слов.
- Используйте прямой порядок слов и активный залог: «Сервис отправляет
  письмо», а не «Письмо отправляется сервисом».
- Избегайте отглагольных существительных: «проверить данные», а не
  «осуществить проверку данных».
- Не используйте слова, которые нельзя проверить: «быстро», «удобно»,
  «красиво», «корректно». Заменяйте их измеримыми значениями.

## Шаги и действия

- Шаги воспроизведения и инструкции оформляются нумерованным списком.
- Каждый шаг содержит одно действие и начинается с глагола в повелительном
  наклонении: «Откройте», «Нажмите», «Введите».
- После шагов указывается результат: фактический — для ошибок, ожидаемый —
  для всех типов задач.

## Обращение к читателю

В описании задачи читатель не упоминается. В шагах воспроизведения
используется обращение на «вы» в повелительном наклонении. В комментариях
к исполнителю допустимо обращение по имени через упоминание `@имя`.

## Однозначность

- Указывайте конкретный объект: «кнопка «Сохранить» в карточке клиента»,
  а не «кнопка».
- Указывайте окружение: стенд, версию сборки, браузер, устройство.
- Не используйте местоимения «он», «это», «там», если из контекста неясно,
  к чему они относятся.
