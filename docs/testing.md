# Тестирование стайлгайда

Стайлгайд проверен на двух задачах учебного интернет-магазина: ошибке и
пользовательской истории. Для каждой задачи приведены исходный вариант и
вариант, оформленный по правилам руководства.

## Пример 1. Ошибка

### Исходный вариант

> **Тема:** не работает корзина!!
>
> **Описание:** Удаляю товар — ничего не происходит. Скрин в чате.

Нарушения: тема без указания места и условия, восклицательные знаки,
разговорный стиль, нет шагов воспроизведения, ожидаемого результата и
окружения, вложение заменено ссылкой на чат.

### Вариант по стайлгайду

**Тема:** Корзина: товар не удаляется при нажатии «Удалить»

**Тип:** Bug. **Приоритет:** High. **Компонент:** Cart.

```markdown
## Окружение
- Стенд: stage
- Версия сборки: 2.14.0
- Браузер или устройство: Chrome 130, Windows 11

## Предусловия
Пользователь авторизован, в корзине 2 товара.

## Шаги воспроизведения
1. Откройте страницу «Корзина».
2. Нажмите «Удалить» у первого товара.

## Фактический результат
Товар остаётся в корзине. В консоли браузера ошибка
`DELETE /api/cart/items/15 — 403`.

## Ожидаемый результат
Товар удаляется из корзины, сумма заказа пересчитывается.

## Частота
Всегда.

## Вложения
cart-delete-error.png
```

## Пример 2. Пользовательская история

### Исходный вариант

> **Тема:** Фильтр
>
> **Описание:** Нужен фильтр по заказам, чтобы было удобно.

Нарушения: тема из одного слова, оценочное слово «удобно», нет роли и
ценности, нет критериев приёмки.

### Вариант по стайлгайду

**Тема:** Добавить фильтр заказов по статусу

**Тип:** Story. **Приоритет:** Medium. **Эпик:** Личный кабинет.

```markdown
## История
Как покупатель, я хочу отфильтровать заказы по статусу, чтобы быстро
найти неоплаченные заказы.

## Контекст
Сейчас в личном кабинете все заказы показываются одним списком.
У активных покупателей более 50 заказов.

## Критерии приёмки
- [ ] Над списком заказов есть выпадающий список «Статус».
- [ ] При выборе статуса «Не оплачен» в списке остаются только
      неоплаченные заказы.
- [ ] Выбранный фильтр сохраняется после обновления страницы.
- [ ] Список с фильтром загружается не дольше 2 секунд при 100 заказах.

## Макеты и материалы
- Макет фильтра заказов в Figma
```

## Оценка результатов

| Критерий | Исходные задачи | Задачи по стайлгайду |
| --- | --- | --- |
| Понятно, что сделать | Частично | Да |
| Можно проверить результат | Нет | Да, по критериям приёмки |
| Ошибка воспроизводится | Нет | Да, по шагам и окружению |
| Термины единообразны | Нет («скрин», «корзина не работает») | Да |
| Время на заполнение | 1 минута | 5–7 минут |

Шаблоны и чек-лист позволили оформить обе задачи по одной схеме, а
критерии приёмки стали проверяемыми. При тестировании выявлены и
исправлены недостатки:

- не было правила для частоты воспроизведения — добавлен раздел
  «Частота» в шаблон ошибки;
- слово «скриншот» встречалось в разных формах — в глоссарий добавлен
  термин «снимок экрана»;
- не было указано, что делать с пустыми разделами шаблона — добавлено
  правило об их удалении.

Итог: стайлгайд пригоден для применения. Заполнение задачи занимает
больше времени, но сокращает число уточняющих вопросов и возвратов задачи
на доработку.
